## 🚀 الخطوات التالية (على Mac)

### ⚠️ مهم جداً
**لا يمكن بناء iOS إلا على Mac + Xcode**  
البيئة الحالية (Linux) أكملت 100% من الإعداد

### على Mac، اتبع الخطوات التالية:

#### 1. نقل المشروع
```bash
# طريقة 1: Git Clone
git clone https://github.com/mwr0855-rgb/Weij.git
cd Weij

# طريقة 2: نسخ مباشر
# انسخ مجلد المشروع بالكامل إلى Mac
```

#### 2. تثبيت الأدوات
```bash
# تثبيت Xcode من App Store
# ثم تثبيت Command Line Tools
xcode-select --install

# تثبيت Flutter
git clone https://github.com/flutter/flutter.git -b stable
export PATH="$PATH:`pwd`/flutter/bin"

# تثبيت CocoaPods
sudo gem install cocoapods
```

#### 3. تجهيز المشروع
```bash
# في مجلد المشروع
chmod +x ios_build.sh
./ios_build.sh

# أو يدوياً:
flutter pub get
cd ios
pod install
cd ..
```

#### 4. فتح في Xcode
```bash
open ios/Runner.xcworkspace
```

#### 5. الإعدادات في Xcode
```
1. اختر Runner من القائمة اليسرى
2. اذهب إلى Signing & Capabilities
3. أضف Apple Developer Account
4. اختر Team
5. غير Bundle ID إلى: com.amrai.medaad
6. تأكد من تفعيل Automatically manage signing
```

#### 6. إضافة Firebase
```
1. حمّل GoogleService-Info.plist من Firebase Console
2. اسحبه إلى Runner في Xcode
3. تأكد من Copy items if needed
4. راجع FIREBASE_iOS_SETUP.md للتفاصيل
```

#### 7. البناء والاختبار
```
# للاختبار على Simulator
1. اختر iPhone Simulator من الأعلى
2. اضغط ▶️ (Cmd + R)

# للاختبار على جهاز حقيقي
1. وصّل iPhone بكابل
2. اختر الجهاز من القائمة
3. اضغط ▶️ (Cmd + R)
```

#### 8. إنشاء Archive للنشر
```
1. Product → Archive
2. انتظر حتى ينتهي البناء (5-15 دقيقة)
3. في Organizer: Distribute App
4. اختر App Store Connect
5. Upload
6. انتظر المعالجة (10-30 دقيقة)
```
